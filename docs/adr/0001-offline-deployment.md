# 测试和生产采用离线部署

Omega V1 的测试和生产目标环境通过文件传入发布物，部署过程不能依赖外网。用户在 2026-09-26 的方案访谈中选择离线部署，而不是要求服务器访问镜像仓库；因此交付必须包含目标环境所需的镜像和部署材料，不能只给出远端镜像引用。

开发与构建允许联网；测试、生产的部署和运行不依赖外网。发布包在联网构建环境生成，包含目标架构所需的应用及第三方组件镜像和部署材料；操作系统、Docker Engine、Compose 插件及基础工具由运维预装，Omega 负责预检和明确报错，不负责安装这些宿主机工具。

共享测试和生产的域名、证书和私钥由部署方提供，Omega 负责检查、挂载和受控重载，不能依赖在线证书签发。已确认的发布物包括镜像归档、部署材料、无凭据模板、发布清单和证据；导入后核对镜像内容身份与平台，文件按可信预期校验值核对。同包校验和不等于发布者签名。
