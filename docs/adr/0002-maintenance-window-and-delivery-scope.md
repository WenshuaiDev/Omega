# V1 允许维护窗口，备份恢复不在本次范围

Omega V1 允许计划内停机升级：停止应用写入后迁移、更新并验证，不承诺零停机。这使首版可以用明确的单机操作顺序交付，避免为尚未定义的业务提前承担并行版本运行和在线切换的复杂性。

用户于 2026-09-26 明确收窄范围：“本次就不考虑备份恢复的问题了”。因此本次不设计或实现备份、恢复、调度、保留、异机副本、恢复演练或 RPO/RTO 要求，也不以升级前备份为发布前置条件；之前第二轮确认的相关建议撤回。

正常停止和重复启动仍须保留持久化数据，这项运行约束不属于备份恢复功能。升级失败时保持维护状态，保留数据、日志和迁移状态，不自动回退数据库；只有明确确认数据库兼容时才允许切回旧镜像，否则停止并报告，后续修复另行处理。用户在第三轮确认了此规则；本次不承诺所有升级失败都能回退。
