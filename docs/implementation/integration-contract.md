# Issue #13 implementation coordination

Authoritative scope: https://github.com/WenshuaiDev/Omega/issues/13 . This file coordinates parallel implementation; it does not replace the spec.

- Go module: `github.com/WenshuaiDev/Omega/services/api`, root `go.work`. Binaries `omega-api`, `omega`. API port 8080. Internal `/health/live`, `/health/ready`; public `/api/v1/ping`.
- CLI: `omega [--config PATH] [--json] version|config validate|doctor|health check|db status|db migrate|data ensure`. `--config` accepted before commands. Config YAML fields: `environment` (dev/test/prod), `instance_id`, `http` (`address`, `shutdown_timeout`), `database` (`host`, `port`, `name`, `user`, `password_file`, `sslmode`, `connect_timeout`), `operation_timeout`. Durations strings. Each role gets complete config. API uses runtime role, CLI migrate/ensure uses migration role. Config/secret mounting paths `/etc/omega/app.yaml`, `/run/secrets/db_password`.
- Database: db `omega`, roles `omega_migrator`, `omega_runtime`; initialization admin postgres. Infrastructure creates db/roles and grants migration role database CREATE; backend owns schema/table/default privileges and migration/identity logic. Runtime only read/write required application objects; installation metadata read-only. Backend documents exact grant contract.
- Reference apps: `apps/web`, `apps/console`. Fixed bases `/web/`, `/console/`; Vite listen 5173 on each app container. Root Yarn 4 node-modules single lock, TS 6.0.3. Runtime JSON: `schemaVersion: 1`, `appId: web|console`, `environment: dev|test|prod`, `version: STRING`, `apiBaseUrl: /api`. No backend secrets. Frontend validate exact fields and matching app/environment enum. Ping response includes `project`, `environment`, `version`, `status`; backend may include instance_id.
- Image definitions: `services/api/Dockerfile` targets `development` and `production`; `apps/Dockerfile` build arg `APP=web|console`, targets `development` and `production`; `infra/edge/Dockerfile`; `infra/tools/Dockerfile`. Release build args `VERSION`, `COMMIT`. Dev binaries from current source. Frontend prod container port 8080.
- Compose: `compose.yaml`, `compose.dev.yaml`, `compose.release.yaml`, `compose.test.yaml`, `compose.prod.yaml`. Services `db`, `api`, `web`, `console`, `edge`; one-off tasks explicit. Database volume `db_data`; Compose project derived only from stable instance id. Instance inputs outside release, dev defaults `.omega/dev` (ignored); scripts accept explicit input path.
- Ownership: backend agent owns `services/`, `go.work*`; frontend owns root package/yarn/TS/lint/format and `apps/`, any actual frontend shared package; dev agent owns Makefile, `compose*`, `infra/`, `config/`, development scripts. Release agent later owns release/deploy scripts. Each agent documents commands/contract details in `docs/implementation/<area>.md` and reports integration changes through context pointers.
- No CI, business entities, backup/recovery, Docker socket in application containers, host-wide cleanup, latest tags, or fabricated acceptance. Native Linux amd64 evidence remains pending if no host exists.
