# Domain Docs

This is a single-context repository. Read root `CONTEXT.md` and relevant
ADRs under `docs/adr/` before exploring an affected area.

If those files do not exist, proceed without requiring them. Domain-modeling
work creates them when terms or decisions are established.

Use terms defined in `CONTEXT.md` consistently. Flag a conflict with an
existing ADR explicitly instead of silently overriding it.
